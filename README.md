第80回 国民スポーツ大会 水泳競技・飛込（2026年9月10日〜12日／セントラルスポーツ宮城Ｇ21プール・宮城県利府町）の
出場選手・飛順と、終わった種目の結果をスマホから確認できるページです。

- 出場 **64名**（男子36名・女子28名）／**36都道府県**／全**8種目**・エントリー**108件**
- **鹿児島県は2名**。久保 彪（高3・飛板飛込／高飛込の2種目）と坂之上 卓（成年男子 高飛込）
- 「選手でさがす」と「日程・飛順」の2画面。日程は競技をタップすると飛順が開きます
- 選手名・都道府県で検索（**ひらがな3文字以上**でも検索できます）
- 男子=青・女子=赤で色分け、鹿児島県は金色で表示
- 出場者がいない都道府県も一覧で確認できます

`index.html` の1枚だけで動きます（ダブルクリックでも開けます）。

## 検算

108件・64名を1件ずつ照合して作成しています。

- 1日目の3種目（37件）は、公式のスタートリストと**氏名・都道府県・人数・開始時刻がすべて一致**
- 各種目に同じ都道府県が2人いないこと、1人が3種目以上に出ていないこと、
  1県の選手が4名を超えていないこと、種別（成年・少年）と男女が種目と合っていることを確認済み
- 飛順が各種目で1から連番になっていること、合計108行になることを画面側でも確認

飛順や出場者は変更されることがあります。最終的な内容は大会の公式発表をご確認ください。

## ふりがな検索

1日目の3種目に出る37名は公式のふりがなで検索できます。
残る27名は名簿にふりがなが無いため、KANJIDIC2（EDRDG, CC BY-SA 4.0）の音・訓・名乗りから
読み候補を組み立てて照合しています。推定なので、読みは画面には表示していません。

`髙/高`・`濵/浜` のような異体字は、どちらで検索しても同じ選手に当たります。

**注意**: 読み候補を作るとき、1文字の読み（之=の、斗=と、汰=た、音=と など）を落としてはいけません。
落とすと「さかのうえ」で坂之上選手が引けなくなります（作成時に実際に踏んだ）。

## 作り方のメモ

  （`build_data.py` が不一致を全部出す。ここが通らなければ公開しない）
- 棄権は公式のスタートリストに出ている分だけを表示している
